# Variation Builders — Client

This is a minimal React + Vite starter to work with the server scaffold.

Quick start

```powershell
cd "c:\Users\Administrator\Desktop\VARIATION WEBSITE\client"
npm install
npm run dev
```

The dev server proxies to `/api` endpoints on the same host by default in this simple setup; if you run the backend on `http://localhost:4000`, configure a proxy or use absolute URLs in `axios` calls.
